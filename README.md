# vowifi-watch

Android-приложение для мониторинга VoWiFi и автоматического восстановления IMS-регистрации в доверенных Wi-Fi сетях. Проект ориентирован на Xiaomi HyperOS, где стандартных исключений Android может быть недостаточно из-за фоновой заморозки Greezer.

## Возможности

- Периодическая проверка Wi-Fi, состояния IMS и пользовательского переключателя VoWiFi.
- Восстановление переключателя VoWiFi и перезапуск IMS через root или локальный ADB.
- Дополнительные шаги восстановления: перезапуск Wi-Fi, цикл авиарежима и пользовательская команда.
- Проверка результата команд повторным чтением состояния.
- Восстановление записей приложения в `MILLET_NO_RESTRICT_APP` и `com.miui.game.allowlist` с сохранением других пакетов.
- Foreground service, watchdog и журнал последних событий.

Приложение использует скрытые и vendor-specific интерфейсы Android/HyperOS. Их поведение зависит от прошивки; перед использованием на другом устройстве необходимы проверки. Автоматические действия могут влиять на связь, поэтому предусмотрены подтверждающие проверки, ограничение попыток, cooldown и запрет remediation во время активного использования телефона.

## Требования

- JDK 17 или новее.
- Android SDK с platform android-34 и build-tools 34.0.0.
- Для полноценной работы на устройстве: root или сопряжённый локальный ADB через беспроводную отладку.

## Сборка и тесты

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
```

APK создаётся по пути `app/build/outputs/apk/debug/app-debug.apk`.

Unit-тесты находятся в `app/src/test/` и покрывают:

- точное сопоставление пакетов и сохранение записей в обоих списках исключений HyperOS;
- разбор ответа Binder о состоянии переключателя VoWiFi;
- выбор последней IMS-регистрации и отбрасывание записей до загрузки, из будущего и с malformed timestamp.

## Установка и настройка

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

В приложении запросите разрешения на телефон, геолокацию и уведомления. Для SSID при выключенном экране нужна геолокация «В любом режиме». На Xiaomi включите автозапуск и режим «Без ограничений», а также исключите приложение из оптимизации батареи Android.

Локальный ADB требует одноразового сопряжения через беспроводную отладку. После перезагрузки её может потребоваться включить заново. Ключи сопряжения хранятся только в приватных данных приложения и не входят в репозиторий.

## Приватность

В репозитории нет журналов устройств, диагностических дампов, ключей ADB, SSID реальных сетей, локальных путей SDK или истории разработки. Публикуются только исходный код, тесты и конфигурация сборки.
